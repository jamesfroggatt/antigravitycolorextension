# Changelog

## 0.1.0

First release.

- Sidebar panel with four cards: Header Title, Outer Frame, Inner Surfaces and Presets.
- Live frame colouring: title bar, window border, activity bar and status bar, with automatic readable text.
- Live inner-surface "grays": editor, sidebars & Claude Code, tabs, panel & terminal, with quick gray buttons.
- Bold window titles in four styles, plus an optional status bar pill.
- Built-in and saved presets, shared across every window.
- Optional "Keep colours out of git".
- Reset to theme default.
- Works in Antigravity IDE and VS Code 1.85+.
